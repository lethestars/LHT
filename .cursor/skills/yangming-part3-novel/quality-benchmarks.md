## 2. 第三部正文质量标记（从定稿章提炼）

写作时对齐以下 **可观测特征**，而非复制情节。

### 结构比例

- **非 H**：通常 1–5 段完成因果（第30章白毅队长仅数行；第29章家法一段后切工地）。  
- **H**：占全章 60%–85% 篇幅；多段递进（铺垫→露出→插入→高潮→拔出/余韵）。  
- **禁止**：正文内小标题（「肉量博弈：」类）。

### 开篇与转场

- 可直接 **承接上章后果**（第29章「没有不透风的墙」接第28章）。  
- 可用 **「画面再次转向…」** 切换场景（第30章韩啸别墅）。  
- 时间词明确：翌日、当晚、下午。

### 对话

- 短句、口语、粗痞可；**一行不宜过长**。  
- 队长/猛男：命令、挑衅、夸体格子；少用书面语。

### 感官与数值

- **数值**：仅首次完整露出 + 高潮节点（第30章陆×白凡 apartment 报 25×6；Combat 段少报数）。  
- **勃起**：半软→套弄/口交→充血（第29章严家法「半硬→充血挺立」）。  
- **词汇**：肉棒/巨屌/鸡巴轮换；同段少刷颜色词。  
- **胸部**：巨胸/胸肌 + 体量描写；少拟物（肉山、长枪）。

### H 段物理与逻辑

- 链式/多人：**顺序写清**（第30章徐×陆 + 胡×白→四人链→高潮传导）。  
- 拔出：**谁插谁才写拔出**（第30章白凡无外插则写疲软/喷精）。  
- 射精：量多、连锁反应可写（第30章徐虎→陆凯→白凡→胡岩）。  
- **双龙**：仅同穴双根；一口一后写「夹击/夹攻」。

### 角色声线（节选）

| 角色 | 标记 |
|:--|:--|
| 陆凯 | 体育生蛮力、口语「老子」、对外冷对熟热 |
| 严立锋 | 火爆、高热红铜、主导句短 |
| 胡岩 | 憨直口语「白老师」「二虎」 |
| 徐虎 | 对韩啸宠溺；对陆凯「虎哥」线 |
| 赵霆宇 | 军痞、护短、「自家崽子」 |

*新人 **顾骁阳**：健气帅、小虎牙、阳光粗口夸体格子；参照 **邵晓杰** 阳光但体量升档。*

## 3. 创作前强制步骤（质量）

1. 在 §1 表选出 **2 篇参照章**。  
2. **Read 工具精读**参照章全文（不只读大纲）。  
3. 输出 **参照对齐说明**（300 字内）：本章节选哪几段结构/笔力对齐哪章。  
4. 写完初稿后自检：比例、数值窗口、链式逻辑、角色声线是否与参照同级。
