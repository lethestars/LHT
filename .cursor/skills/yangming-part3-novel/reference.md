## 历史剧情查询顺序

1. `canon-registry.md` → 快查进度/伏笔  
2. `剧情大纲.md` 第五节 → 该章完整记录  
3. `人物设定.md` 关系索引 → 两角色间全部过往  
4. 原文 `第N章·….md` → 细节与文风  

**写第 N 章时至少读**：第 N−1 章全文 + 第 N 章大纲第五节 + 相关角色关系索引全部条目。
