# 阳明宇宙·第三部 · 小说创作 Skill

硬性规则：`.cursor/rules/novel-multi-agent-collab.mdc`。本 Skill 负责 **Canon 记录、质量参照、操作顺序**。

---

## Canon 三层（人设 + 历史剧情）

| 层 | 内容 | 文件 | 何时更新 |
|:--|:--|:--|:--|
| **静态人设** | 体格、性器、性格、性癖 | `人物设定.md` 角色档案 | 新角色/设定变更 |
| **动态关系** | 分章谁与谁对戏、H 分工 | `人物设定.md` 关系索引 | **每章定稿后** |
| **历史剧情** | 全章因果、H 详述、伏笔 | `剧情大纲.md` 第三–五、七节 | **每章定稿后** |
| **状态快照** | 写到了哪、未回收伏笔、角色最近状态 | [canon-registry.md](canon-registry.md) | **每章定稿后** |

**冲突裁决顺序**：`人物设定.md` ＞ `第三部通用词库.md` ＞ `剧情大纲.md` ＞ `写作规范.md` ＞ 用户当次指令。

**禁止**：正文新增剧情不回写大纲/关系索引/登记册；禁止只改正文不更新 Canon。

---

## 写新章前 · 强制阅读（按序）

1. [canon-registry.md](canon-registry.md) §1–§2（进度 + 待回收伏笔）  
2. `剧情大纲.md` 第三节 + **上一章 & 本章** 第五节详述 + 第四节速览  
3. **本章全部 H 参与角色** → `人物设定.md` 档案 + 关系索引中该角色全部条目  
4. [quality-benchmarks.md](quality-benchmarks.md) → 选 **2 篇参照章**，**Read 精读正文全文**（不只读大纲）  
5. 输出 **参照对齐说明**（300 字内：结构/笔力对齐哪章）→ 再写硬约束清单 → 初稿  

**第 31 章建议参照**：第29章、第28章、第25章或第2章（见 quality-benchmarks §1）。

---

## 正文质量 · 对齐已定稿章节

第三部定稿章（1–30）为 **质量基准**。新章须对齐 [quality-benchmarks.md](quality-benchmarks.md) 中的：

- 非 H / H 篇幅比  
- 对话密度与声线  
- 数值窗口、勃起过程、链式/拔出逻辑  
- 无正文小标题  

**勿**：只凭大纲臆写而未读参照章正文。

---

## 四 Agent 工作流（摘要）

1. **Agent1**：硬约束清单 → 参照对齐说明 → 正文初稿  
2. **Agent2/3/4**：并行审核（人设 / 词库文风 / 逻辑规范）→ 格式见 [reference.md](reference.md)  
3. **Agent1**：合并整改  
4. **循环至用户回复「满意」**  

返工：严重→重写该段；中等≥3→整章返工。

---

## 定稿后 · Canon 同步清单（必做）

用户「满意」后按序执行：

```
- [ ] 剧情大纲.md：第四节速览 + 第五节该章详述 + 第三节伏笔 + 第七节 H 统计
- [ ] 人物设定.md：关系索引（本章每个直接对戏角色，写清章号与肉戏/剧情分工）
- [ ] canon-registry.md：§1 最新章 + §2 伏笔 + §3 追加一行 + §4 角色最近状态
- [ ] python3 scripts/canon_check.py   # 检查登记与正文是否脱节
- [ ] python3 scripts/build_fullbook.py  # 全本整合（用户未禁止时）
- [ ] Git commit 仅用户明确要求时
```

关系索引写法：`第N章` + 具体互动；定稿后删除「计划」字样。

## 正文硬约束速查

| 项 | 规则 |
|:--|:--|
| 数值 | ≤30/10/60吋；仅首次露出+高潮；禁 soft 态数字；禁 Xcm×Ycm 连写 |
| 勃起 | 半软→刺激→充血 |
| 双龙 | 仅同穴双根同时 |
| 语言 | 简体中文；无英文 |
| 胸部 | 胸肌/巨胸；少拟物比喻 |
